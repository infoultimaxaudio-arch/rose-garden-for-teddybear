THE ROSE GARDEN OF TEDDYBEAR
A separate multi-chapter interactive rose experience.

Includes:
- Secret invitation opening
- Click-to-bloom virtual rose
- Flower garden with hidden thoughts
- Five petal message reveals
- Star connection mini-game: connect all 10 stars in order to draw a heart
- Flip promise cards
- Press-and-hold virtual hug
- Falling petals and transitions
- Optional background music

Music: add your MP3 to assets/ and name it your-song.mp3.
Browsers may require the visitor to tap the Music button before sound plays.

Deploy separately:
1. Create a NEW GitHub repository, e.g. rose-garden-for-teddybear.
2. Upload index.html, style.css, app.js, README.txt and assets folder.
3. Netlify > Add new project > Import an existing project > GitHub.
4. Select this new repository. Leave build command blank; publish directory is .
5. Deploy.

Do not upload these files into your existing Sorry Page or Open When repositories.
